# 공부왕 (Study King)

> 공부왕은 오늘 공부한 과목을 기록하고,  
> 나만의 공부 히스토리를 만들어가는 심플한 스터디 트래커 앱입니다.

---

## 주요 기능

- ✅ 과목별 공부 완료 기록
- ✅ 오늘 완료한 공부 과목 히스토리 저장
- ✅ 3개월 이내 기록만 자동 유지
- ✅ 공부 데이터 대시보드 제공 (추후 업데이트 예정)
- ✅ Firebase 기반 클라우드 저장

---

## 앱 화면

- 로딩 화면
- 로그인 화면 (Google 계정 연동)
- 메인 공부방 (캐릭터 움직임)
- 공부 시작 → 과목 선택 → 공부 완료 흐름
- 공부 히스토리 목록
- 향후 대시보드/통계 기능 추가 예정

---

## 🛠️ 사용 기술

- **Unity 2022**
- **Firebase Authentication**
- **Firebase Firestore Database**
- **C# (.NET 기반 스크립팅)**
